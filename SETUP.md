# КНН трекер — как запустить

Личный трекер пар Всеволода Спивака. Группа по умолчанию **3426А**. Сайт — мобильное PWA на русском. Расписание сейчас из скриншотов таблицы на **29.10.2026**. Напоминания — в MAX.

- Репозиторий: https://github.com/Xrex-collab/knn-tracker
- Сайт: https://xrex-collab.github.io/knn-tracker/

|---|---|---|

Группу можно сменить в приложении («Ещё»), выбор хранится на устройстве. Новые дни: вкладка «Ещё» → фото скрина + форма «Добавить пару». Правки на телефоне живут в браузере; для напоминаний в MAX нужен актуальный `state/schedule-data.json` в репозитории.

Сайт закрыт логином. Это **замок от чужих глаз** на GitHub Pages, не банковская защита: PBKDF2-хеш в `docs/auth.json` публичный, его можно подобрать перебором. `docs/data/schedule.json` зашифрован AES-GCM (как DATA_KEY в space32-web/big-hit-monstr). GitHub Actions читает открытую копию `state/schedule-data.json` (Pages её не отдаёт). В истории `main` до этого коммита JSON ещё открытый.

Логин по умолчанию: **vsevolod**. Пароль в репозиторий не кладётся — его выдают отдельно.

## 1. GitHub Pages

Сайт лежит в `docs/` на ветке `main`. Источник Pages: **Deploy from a branch** → `main` / `/docs`.

Если в Settings → Pages список веток пустой (репозиторий только что получил `main`):

1. Открой https://github.com/Xrex-collab/knn-tracker/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/docs**
4. Save

На телефоне: открой сайт → войди → «Поделиться» / меню → **На экран «Домой»**.

## 2. Пароль и пользователи

Файл `docs/auth.json` — логины и хеши, не сами пароли. Общий ключ `DATA_KEY` лежит только в `secrets.local.txt` (в git не попадает) и оборачивается паролем каждого пользователя.

Сменить пароль Всеволода (расписание перешифровывать не нужно):

```bash
node scripts/users.mjs password vsevolod --old 'старый' --password 'новый'
```

Добавить ещё одного человека (тот же `DATA_KEY`, свой пароль):

```bash
DATA_KEY=... node scripts/users.mjs add anna "Анна" --password '...'
```

После правки открытого JSON:

```bash
# замени state/schedule-data.json
DATA_KEY=... node scripts/users.mjs encrypt
```

`DATA_KEY` можно не печатать, если он уже в `secrets.local.txt`.

## 3. MAX-бот и секреты

Напоминания **не ходят**, пока нет токена и id чата. Секреты в репозиторий не класть.

1. Открой [dev.max.ru](https://dev.max.ru) → чат-боты → создай бота → скопируй токен (⋮ → Настройки).
2. Напиши боту в MAX любое сообщение (иначе личные сообщения не дойдут).
3. Узнай свой **user_id** (диалог с ботом) или **chat_id** (группа/канал, куда добавлен бот). Как получить id — в [документации MAX](https://dev.max.ru/docs-api).
4. В репозитории: Settings → Secrets and variables → Actions:
   - `MAX_TOKEN` — токен бота
   - `MAX_USER_ID` **или** `MAX_CHAT_ID` — куда слать
5. Workflow `.github/workflows/notify.yml`: cron каждые 10 минут с 06:00 до 21:59 по Москве.
   - **07:00** — сводка пар на сегодня
   - **за ~20 минут до пары** — предмет и время начала

GitHub может задержать cron на 5–15 минут, поэтому окно напоминания — 20 минут.

Локальная проверка (ничего не отправляет):

```bash
node scripts/notify.mjs --dry --now 2026-10-29T17:10
```

## 4. Новые скрины расписания

Таблицы Google / Яндекс Диск **не используются**.

1. Сфоткай лист таблицы.
2. В приложении: «Ещё» → «Скрин расписания» → выбрать фото.
3. Внеси пары формой (дата, начало, конец, предмет, преподаватель).
4. «Скачать JSON» и замени `state/schedule-data.json`, затем `node scripts/users.mjs encrypt` — иначе сайт и MAX разъедутся. Скрины клади в `state/screenshots/`, не в `docs/` (Pages не должен их отдавать).
